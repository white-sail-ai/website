# Company logos

Curated US company marks (`/logos/{TICKER}.png` or `.svg`) and ETF issuer artwork (`/logos/etf-issuer/`). Sourced from the AI-repo copy of [nvstly/icons](https://github.com/nvstly/icons).

Refresh popular tickers:

```bash
node scripts/fetch-logos.mjs
node scripts/fetch-logos.mjs AAPL NVDA MSFT
```

Israeli paper-number logos are not included.
